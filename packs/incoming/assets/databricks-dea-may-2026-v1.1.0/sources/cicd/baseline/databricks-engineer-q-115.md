# Reviewed baseline question 115

Question: What is the databricks CLI used for?

Reviewed answer: To interact with Databricks programmatically: manage clusters, jobs, workspaces, and run commands from local machines or CI/CD pipelines

The Databricks CLI enables programmatic interaction with Databricks: create/manage clusters, submit jobs, import/export notebooks, manage Unity Catalog objects, deploy Declarative Automation Bundles, and more. It is essential for automation, CI/CD pipelines, and scripting Databricks operations.
