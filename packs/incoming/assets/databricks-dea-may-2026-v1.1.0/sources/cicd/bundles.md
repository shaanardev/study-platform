# Declarative Automation Bundles

Declarative Automation Bundles (formerly Databricks Asset Bundles) define a project, its code, resources, and deployment configuration as versioned files. A bundle can use targets for environment-specific workspace and resource settings. Promote a reviewed source revision through the intended targets to make deployment repeatable; tests and runtime authorization checks remain separate responsibilities.
