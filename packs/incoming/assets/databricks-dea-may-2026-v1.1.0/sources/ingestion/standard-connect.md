# Standard and managed connectors

Reviewed source digest for the May 2026 practice pack. Use the linked documentation for platform and runtime details.

Standard connectors expose Spark or SQL APIs and give pipeline authors more control over processing. Managed connectors automate more source-specific ingestion setup and operation. Compare support and customization requirements.

Primary reference: [https://docs.databricks.com/aws/en/ingestion/](https://docs.databricks.com/aws/en/ingestion/)
