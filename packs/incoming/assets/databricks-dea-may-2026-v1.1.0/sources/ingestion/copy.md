# COPY INTO file ingestion

Reviewed source digest for the May 2026 practice pack. Use the linked documentation for platform and runtime details.

COPY INTO loads files from cloud object storage and tracks files processed by prior runs. A rerun can load new files; force options can replay known files, so account for duplicate effects.

Primary reference: [https://docs.databricks.com/aws/en/ingestion/cloud-object-storage/copy-into](https://docs.databricks.com/aws/en/ingestion/cloud-object-storage/copy-into)
