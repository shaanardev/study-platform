# Governed file upload and access

Reviewed source digest for the May 2026 practice pack. Use the linked documentation for platform and runtime details.

A workstation path is not available to distributed compute. Upload files to supported governed storage, such as a Unity Catalog volume, then read with format and schema options appropriate to the contents.

Primary reference: [https://docs.databricks.com/aws/en/volumes/volume-files](https://docs.databricks.com/aws/en/volumes/volume-files)
