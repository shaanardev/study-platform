# Reviewed baseline question 112

Question: What do Declarative Automation Bundles provide for a data engineering team?

Reviewed answer: Versioned configuration and code for reproducible deployment of jobs, pipelines, and related workspace resources

Bundles, formerly Declarative Automation Bundles, package resource definitions and code for development and CI/CD. They integrate with Git and the Databricks CLI. They do not replace tests or automatically grant privileges.
