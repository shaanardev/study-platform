# Reviewed baseline question 171

Question: A developer has committed a notebook fix on a feature branch in a Databricks Git folder. What makes it available for remote review?

Reviewed answer: Push the branch and create a pull request in the Git provider

A local commit records history in the Git folder. Pushing publishes commits to the remote branch, where a pull request supports review before merging. Notebook history and table time travel do not publish a Git branch.
