An open-source storage layer that brings ACID transactions to Apache Spark and big data workloads

Delta Lake is an open-source storage layer that runs on top of existing data lakes (like S3, ADLS, GCS). It provides ACID transactions, scalable metadata handling, and unified streaming/batch data processing. Delta Lake is not proprietary to Databricks and is a Linux Foundation project.
