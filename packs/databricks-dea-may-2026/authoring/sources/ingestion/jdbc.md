# Spark JDBC data source

Reviewed source digest for the May 2026 practice pack. Use the linked documentation for platform and runtime details.

Spark reads supported relational databases through a JDBC driver and connection. Incremental cursors, delete capture, and retry-safe destination effects are pipeline responsibilities.

Primary reference: [https://spark.apache.org/docs/3.5.7/sql-data-sources-jdbc.html](https://spark.apache.org/docs/3.5.7/sql-data-sources-jdbc.html)
