# Lakehouse Federation

Reviewed source digest for the May 2026 practice pack. Use the linked documentation for platform and runtime details.

Federation provides governed queries against supported external sources without ordinary ingestion into local destination tables. Replication pipelines materialize destination data.

Primary reference: [https://docs.databricks.com/aws/en/query-federation/](https://docs.databricks.com/aws/en/query-federation/)
